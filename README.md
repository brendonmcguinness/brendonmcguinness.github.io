# Brendon McGuinness academic website

Source for Brendon McGuinness's Quarto academic website, published with GitHub Pages.

## Site files

- `index.qmd` — homepage
- `research.qmd` — research narrative
- `publications.qmd` — papers and preprints
- `cv.qmd` — embedded and downloadable CV
- `_quarto.yml` — navigation and site-wide configuration
- `styles.css` — typography, colors, spacing, and responsive layout
- `images/` — website images and research animations
- `files/` — downloadable public files

## Preview locally

```bash
quarto preview
```

Changes to the source files are automatically rendered while the preview is running.

## Publish

```bash
quarto publish gh-pages
```

The site is intended for `https://brendonmcguinness.github.io`.
